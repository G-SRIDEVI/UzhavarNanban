# 🌾 UzhavarNanban – உழவர் நண்பன்
### Your Digital Farming Companion

UzhavarNanban is a smart agricultural platform designed to connect farmers with agricultural dealers, product buyers, and farm machinery owners. It focuses on supporting farmers in Natrampalli Block, Tirupattur District, Tamil Nadu.

## 🚀 Features

### 🌱 AI Plant Doctor
- Upload plant images for preliminary disease identification.
- Receive AI-assisted crop health insights.

### 🧪 Agricultural Product Marketplace
- Connect farmers with pesticide and fertilizer dealers.
- Compare product prices and quotations.
- Discover suitable agricultural products.

### 🛒 Crop Marketplace
- Help farmers list their agricultural produce.
- Connect farmers with potential buyers.

### 🚜 Farm Machinery Rental
- Connect farmers with machinery owners.
- Discover equipment available for rental.

### 🌦️ Agricultural Advisory
- Access agricultural weather information.
- Explore market prices and agricultural schemes.

### 👥 Multiple User Roles
- Farmers
- Agricultural Dealers
- Agricultural Product Buyers
- Farm Machinery Owners

### 🌐 Farmer-Friendly Platform
- Tamil and English language support.
- Responsive web interface.
- Designed with rural accessibility in mind.

## ⚙️ Run Locally

### Backend

1. Navigate to the backend folder.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Start the backend using the entry point configured in your project.

### Frontend

1. Navigate to the frontend folder.
2. Install dependencies:

   npm install

3. Create a `.env.local` file containing:

   VITE_API_URL=http://127.0.0.1:8000

4. Start the development server:

   npm run dev

## 🔐 Security

- Keep passwords, API keys, and database credentials private.
- Never commit sensitive `.env` files.
- Configure CORS appropriately for production.
- Use a persistent database for production data.
